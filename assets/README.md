# Asset Workspace

`placeholders/` contains original geometric development art generated specifically for this design bundle. It is intended to make the future client runnable before final art exists.

`spec/asset-manifest.json` is the contract. Final production art must preserve the IDs/frame dimensions or update the central AssetRegistry and manifest together.

Do not add original Mine Bombers image/audio files here unless a separate, explicit license grants reuse in this new project.

- `ui_icons.png` — 8 x 32×32 equipment/treasure UI placeholder frames.
