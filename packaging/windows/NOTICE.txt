Mine Bombers: Reloaded - notices
================================

The game
--------
Mine Bombers is (c) Skitso Productions (Finland). This project is an unofficial engine port; it is not
affiliated with or endorsed by Skitso Productions. No original game files are included in this package.
Players bring their own copy of the freeware release 3.11.

This project's code
-------------------
The license of this project's code is NOT settled yet.

The engine is based on Ivan Dubrov's mb-reloaded (https://github.com/idubrov/mb-reloaded), which does not
state a license; a request for one is open at https://github.com/idubrov/mb-reloaded/issues/1.
Until that is resolved, this build is published as a pre-release for testing, without a license grant.
Details: DECISIONS.md and assets/LICENSE-NOTES.md in https://github.com/jeiel85/minebombers-reloaded.

If you are a rights holder and want something removed, please open an issue in that repository.

Third-party libraries shipped as DLLs next to MineBombers.exe
-------------------------------------------------------------
The DLLs are shipped as separate files (not linked into the exe), so each one can be replaced by another
build of the same library. The full license texts are in the "licenses" folder of this package.

  File                 Library                       License                       Text in "licenses"
  SDL2.dll             SDL 2.30.8                    zlib                          (see below)
  SDL2_mixer.dll       SDL_mixer 2.8.0               zlib                          LICENSE.SDL_mixer.txt
  libgme.dll           Game Music Emu                LGPL-2.1                      LICENSE.gme.txt
  libxmp.dll           Extended Module Player        MIT                           LICENSE.xmp.txt
  libogg-0.dll         libogg (Xiph.Org)             BSD-3-Clause                  LICENSE.ogg-vorbis.txt
  libopus-0.dll        Opus                          BSD-3-Clause + patent grants  LICENSE.opus.txt
  libopusfile-0.dll    opusfile (Xiph.Org)           BSD-3-Clause                  LICENSE.opusfile.txt
  libwavpack-1.dll     WavPack                       BSD-3-Clause                  LICENSE.wavpack.txt

Provenance. SDL2_mixer.dll and the six DLLs after it are byte-for-byte identical to the files in the official
package SDL2_mixer-2.8.0-win32-x64.zip (1,004,128 bytes, SHA-256
e470282ae88abe5b01acfc3c46cd63b064fd7ef51ba1a3ea0bdf7624347e6549) from
https://github.com/libsdl-org/SDL_mixer/releases/tag/release-2.8.0, and the license texts in "licenses" are
copied unchanged from that package (LICENSE.SDL_mixer.txt is the package's README.txt). SDL2.dll is not part of
that package; it has not been compared with the official SDL2-2.30.8-win32-x64.zip. It is licensed under the
same zlib terms as LICENSE.SDL_mixer.txt (Simple DirectMedia Layer, https://libsdl.org/).

LGPL-2.1 (Game Music Emu, libgme.dll). The library is used unmodified as a separate DLL that you can replace
with your own build. Its source code is at https://github.com/libsdl-org/game-music-emu (branch v0.6.3-SDL,
commit 861c0c865696bb157039b2a6b48e5ae0548983be, the version pinned by SDL_mixer 2.8.0 as external/libgme).
If that location ever goes away, ask for a copy with an issue at
https://github.com/jeiel85/minebombers-reloaded/issues.

The exe itself is built with the Rust standard library and the 89 crates listed in Cargo.lock of the source
repository. Each of them is licensed under MIT, Apache-2.0, Zlib, BSD-3-Clause, ISC or Unlicense terms
(checked with `cargo metadata`). The Microsoft C runtime is linked statically.
