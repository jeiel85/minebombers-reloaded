# 대체 애셋 시범 (이슈 #63)

원작 데이터 없이 배포하는 방향(경로 B, OpenGFX 방식)이 실제로 가능한지 보려고 만든 도구입니다. 게임 스프라이트 시트 `SIKA.SPY`의 일부를 새로 그리고, 엔진이 읽는 SPY 포맷으로 저장합니다. 정식 기능이 아니라 시범용이며, 릴리스와 CI에는 포함되지 않습니다.

## 클린룸 원칙

`gen_sika.py`는 원작 이미지를 읽지 않습니다. 참고하는 것은 엔진 코드뿐입니다.

- `crates/mb-core/src/glyphs.rs`: 각 글리프의 좌표
- `crates/mb-core/src/world/map/level.rs`: 맵 칸의 이름과 값

원작 그림을 보고 따라 그리면 파생물이 되어 독립하는 의미가 없어집니다. 이 도구를 고칠 때도 원작 이미지는 열지 마세요.

## 사용법

Python 3와 Pillow가 필요합니다.

```bash
python tools/asset-pilot/gen_sika.py
```

결과는 `tools/asset-pilot/out/`에 생기고, 이 폴더는 커밋하지 않습니다.

| 파일 | 내용 |
|---|---|
| `SIKA.SPY` | 엔진에 바로 넣을 수 있는 640×480, 16색 시트. 그리지 않은 칸은 0번 색 |
| `sika_pilot.png` | 같은 시트의 PNG |
| `scene_pilot.png` | 엔진의 그리기 규칙대로 합성한 게임 화면(2배). 위쪽 정보 막대는 임시로 그린 것 |
| `sprites_zoom.png` | 그린 스프라이트를 이름과 함께 확대한 표 |
| `walk_p1.gif` | 1P 4방향 걷기 애니메이션 |

## 엔진에서 확인하기

1. 원작 3.11 폴더를 **복사**하고, 복사본의 `SIKA.SPY`를 `out/SIKA.SPY`로 바꿉니다. 원본 폴더는 건드리지 마세요.
2. 평소 설정과 기록이 섞이지 않게 사용자 폴더도 따로 지정해 실행합니다.

   ```powershell
   $env:MINEBOMBERS_USER_DIR = "<빈 폴더>"
   target\release\MineBombers.exe "<복사한 게임 폴더>"
   ```

3. `drive_engine.ps1`로 창에 키를 보내고 화면을 캡처할 수 있습니다. 포커스를 가져가지 않고, PC가 잠긴 동안에도 동작합니다. `System.Drawing`이 필요해서 Windows PowerShell 5.1로 실행합니다.

   ```powershell
   powershell.exe -File tools\asset-pilot\drive_engine.ps1 -Keys "Return" -Wait 1500 -Out shot.png
   ```

## 알아낸 포맷 제약

- **SPY 한 장은 16색입니다.** 768바이트 팔레트 중 앞의 16색(48바이트)만 쓰고, 값은 8비트 RGB 그대로입니다. 그 뒤에 비트플레인 4장이 RLE로 이어집니다. `0x01`이 이스케이프여서 `01 값 개수`가 반복을 뜻하고, 그 외 바이트는 그대로 1바이트입니다. 게임 스프라이트 전부가 이 16색 팔레트 하나를 함께 씁니다.
- **글리프는 불투명하게 복사됩니다**(`src/glyphs.rs`의 `Glyphs::render`). 플레이어나 폭탄 같은 스프라이트는 통로 바탕색까지 포함해 그려야 하고, 모래 속 보물처럼 바탕이 다른 칸에서는 네모난 바탕이 보입니다.
- 게임 스프라이트는 전부 `SIKA.SPY`에 있습니다. `SHAPET.SPY`는 안내 화면 중 하나입니다.

## 시범 범위

그린 것은 지형 21종, 폭탄·다이너마이트 9종, 폭발·연기 3종, 보물·구급상자 5종, 굴 가장자리 16종, 플레이어 4명 × 4방향 × 4프레임입니다.

아직 비어 있는 것은 몬스터, 곡괭이 자세, 보물 일부, 지뢰, 통, 상점 아이콘과 칸, 메뉴 포인터입니다.
