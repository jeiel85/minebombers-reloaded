# Documentation

The documents to trust are the top-level `README.md`, `DECISIONS.md` and `assets/LICENSE-NOTES.md`.

`archive/` holds 19 documents written for an earlier design: a server-authoritative web multiplayer game
in TypeScript on Cloudflare Workers (Durable Objects, Phaser, Vite). That code is no longer in the
repository and the project went a different way (see `DECISIONS.md`, D2), so nothing in them describes the
current code. They are kept for reference only.

The gameplay and classic-mode notes there may be a starting point for the behavior specifications the
engine needs, but check every claim against the original game before relying on it.
